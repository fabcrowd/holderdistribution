# Logos

- `holder-analytics-icon.svg` — icon mark alone, single-ink `brand` teal. Use for favicons, app icons, avatars.
- `holder-analytics-stacked.svg` — icon above wordmark. Default for square/portrait placements.
- `holder-analytics-horizontal.svg` — icon beside wordmark. Default for nav bars and wide headers.

All three are fixed-color (`#017276`), not `currentColor` — see `../BRAND.md`'s Logo usage section for when to swap to solid white instead of recoloring.
