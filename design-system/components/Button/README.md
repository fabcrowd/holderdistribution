# Button

Primary is the brand-filled button — at most one per view, for the action the page is for ("Track this token"). Secondary is an outlined button for everything else. Ghost is text-only, for the lowest-emphasis action in a row (e.g. "Cancel" beside a primary "Save"). Accent (gold) is reserved for a premium or featured action — upgrading a plan, unlocking a paid feature — never a second general-purpose button beside primary. Verb first, sentence case: "Add wallet," not "Wallet Add" or "ADD WALLET."
